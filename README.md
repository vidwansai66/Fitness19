# 🏋️ Fitness19

### Modern Fitness Landing Page for Gyms & Personal Training

A responsive fitness website built with modern web technologies, designed to showcase gym services, trainers, memberships, and motivate users toward a healthier lifestyle.

<br>

🌐 **Live Demo:** https://fitness19.vercel.app/

</div>

---

## 🚀 Overview

Fitness19 is a clean and modern fitness landing page created with a strong focus on user experience, responsive design, and attractive visuals.

The project demonstrates front-end development skills by building a professional fitness website that works seamlessly across desktop, tablet, and mobile devices.

---

## ✨ Features

- 🏋️ Modern Gym Landing Page
- 📱 Fully Responsive Design
- ⚡ Smooth Navigation
- 🎨 Clean & Professional UI
- 💪 Fitness Program Sections
- 👨‍🏫 Trainer Showcase
- 💳 Membership Plans
- 📞 Contact Section
- 🚀 Fast Loading Performance
